What's inside

Every layer earns its place

Deduction-hypothesis engine

Shows the exact fee/GST/TDS formula that explains a variance, not just "amount differs."

Anchored batch completion

Resolves multi-invoice payouts by anchoring on confirmed references first, never a blind ledger-wide search.

Partial-payment tracking

Tracks a remaining balance per invoice across multiple settlements without double-closing it.

Closed-vocabulary exceptions

Every unresolved record gets a reason code — including MODEL_COULD_NOT_DECIDE, the model's own limitation, named separately.

Read-only LLM guardrail

The only model call in the system proposes; it never writes to the ledger without a human confirming.

Hash-chained audit log

Every decision is logged and chained to the one before it — tamper-evident, and independently verifiable.

Multi-seed statistical evaluation

Mean ± std across 5 seeds, plus AUGRC, ECE and decision-determinism (DecDet) — not a single lucky run.

Honeypot / adversarial testing

Deliberately-wrong-but-plausible transactions are injected, and the bait-taken rate is reported honestly.

Work-queue UI

A filter rail, dense table and review panel — a queue to clear, not a dashboard to admire.
